## 1. Анализ предметной области и бизнес-правил

Для выполнения лабораторной работы используется модуль `parking.py`, предназначенный для расчёта стоимости парковки транспортного средства в зависимости от времени стоянки, массы автомобиля и типа двигателя.

### Бизнес-правила:

| № | Правило |
|---|---|
| 1 | Если количество часов (`hours`) меньше 0 или масса (`vehicle_weight_tons`) меньше 0 — вызывается ошибка `ValueError`. |
| 2 | Если количество часов (`hours`) больше или равно 24 — применяется фиксированный суточный тариф (`1000.0`). |
| 3 | Если время стоянки не превышает 2 часов (`hours <= 2`) — тариф составляет `150.0`. |
| 4 | Если время стоянки от 2 до 8 часов (`2 < hours <= 8`) — тариф составляет `400.0`. |
| 5 | Если время стоянки больше 8 часов (`hours > 8`) — базовый тариф `400.0` плюс `50.0` за каждый полный и неполный час свыше 8. |
| 6 | Для электромобилей (`is_electric=True`) применяется скидка 50% на итоговую стоимость парковки. |

### Пример расчёта итоговой стоимости:
* **Время стоянки:** `10` часов
* **Масса автомобиля:** `1.5` тонны
* **Тип двигателя:** бензиновый (`is_electric = False`)
* **Расчёт стоимости:** базовые 8 часов (`400.0`) + 2 часа сверх нормы ($2 \times 50.0 = 100.0$)
* **Итоговая цена:** $400.0 + 100.0 = 500.0$

## 2. Анализ входных и выходных данных

### Входные параметры

| Параметр | Тип | Допустимые значения | Недопустимые значения |
|---|---|---|---|
| `hours` | `float` | Числа `>= 0` | Отрицательные числа (`< 0`) |
| `vehicle_weight_tons` | `float` | Числа `>= 0` | Отрицательные числа (`< 0`) |
| `is_electric` | `bool` | `True`, `False` | Иные типы данных |

### Выходные параметры

| Функция | Выходное значение |
|---|---|
| `calculate_parking_fee()` | Итоговая стоимость парковки (`float`) либо исключение `ValueError` при недопустимых параметрах |

### Классы эквивалентности

| Класс | Условие | Ожидаемый результат |
|---|---|---|
| 1 | `hours < 0` или `weight < 0` | Ошибка `ValueError` |
| 2 | `0 <= hours <= 2` | Тариф `150.0` |
| 3 | `2 < hours <= 8` | Тариф `400.0` |
| 4 | `8 < hours < 24` | Расчёт: `400.0 + (hours - 8) * 50.0` |
| 5 | `hours >= 24` | Фиксированный суточный тариф `1000.0` |
| 6 | `is_electric = True` (любая категория) | Применение скидки 50% к итоговой стоимости |

### Граничные значения

| Параметр или условие | Граничное значение | Ожидаемый результат |
|---|---|---|
| Отрицательное время | `-1` | Выброс `ValueError` |
| Отрицательная масса | `-0.5` | Выброс `ValueError` |
| Нижняя граница категории | `2` часа | Тариф `150.0` |
| Переход на часовую доплату | `8` и `10` часов | Корректный расчёт с шагом `50.0` |
| Предсуточная граница | `23.99` часа | Расчёт по формуле `400 + (15.99 * 50) = 1199.5` |
| Суточный фиксированный тариф | Ровно `24` часа (`24.0`) | Сумма `1000.0` |
| Превышение суточного тарифа | `30` часов | Сумма `1000.0` (суточный лимит) |

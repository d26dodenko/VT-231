## 1. Бизнес-правила

Для лабораторной работы используется модуль `delivery_service.py`, предназначенный для расчёта стоимости доставки заказа интернет-магазина.

В модуле реализованы три функции:

- `calculate_delivery_cost()` — рассчитывает стоимость доставки по расстоянию, весу и типу доставки;
- `apply_discount()` — применяет скидку в зависимости от суммы заказа и типа клиента;
- `calculate_final_cost()` — рассчитывает итоговую стоимость заказа с учётом скидки и доставки.

В результате анализа были выделены следующие бизнес-правила:

| № | Правило |
|---|---|
| 1 | Расстояние доставки должно быть больше 0 км. |
| 2 | Вес заказа должен быть больше 0 кг. |
| 3 | При расстоянии до 5 км включительно базовая доставка стоит 150 руб. |
| 4 | При расстоянии более 5 км и до 20 км включительно доставка стоит 250 руб. |
| 5 | При расстоянии более 20 км и до 50 км включительно доставка стоит 400 руб. |
| 6 | При расстоянии свыше 50 км доставка недоступна и вызывается `ValueError`. |
| 7 | Если вес заказа превышает 10 кг, к стоимости доставки добавляется 150 руб. |
| 8 | При экспресс-доставке дополнительно начисляется 200 руб. |
| 9 | Сумма заказа должна быть больше 0 руб. |
| 10 | Допустимы два типа клиента: `regular` и `premium`. |
| 11 | Для клиента `premium` применяется скидка 10% независимо от суммы заказа. |
| 12 | Для клиента `regular` при сумме заказа от 5000 руб. применяется скидка 5%. |
| 13 | Для клиента `regular` при сумме менее 5000 руб. скидка не применяется. |
| 14 | Итоговая стоимость равна стоимости заказа после скидки плюс стоимость доставки. |

### Формулы расчёта

Для обычного клиента при сумме заказа от 5000 руб.:

`OrderWithDiscount = OrderAmount * 0.95`

Для клиента категории `premium`:

`OrderWithDiscount = OrderAmount * 0.90`

Итоговая стоимость:

`FinalCost = OrderWithDiscount + DeliveryCost`

Например, для заказа стоимостью 5000 руб., расстояния 10 км и веса 2 кг обычный клиент получает скидку 5%:

`5000 * 0.95 = 4750 руб.`

Доставка на 10 км стоит 250 руб. Итоговая сумма:

`4750 + 250 = 5000 руб.`

## 2. Анализ входных и выходных данных

### Входные параметры

| Параметр | Тип | Допустимые значения | Недопустимые значения |
|---|---|---|---|
| `distance_km` | `int` или `float` | `> 0` и `<= 50` | `<= 0` или `> 50` |
| `weight_kg` | `int` или `float` | `> 0` | `<= 0` |
| `express` | `bool` | `True` / `False` | отдельная проверка типа не реализована |
| `order_amount` | `int` или `float` | `> 0` | `<= 0` |
| `customer_type` | `str` | `regular`, `premium` | любые другие значения |

### Выходные значения

| Функция | Результат |
|---|---|
| `calculate_delivery_cost()` | Стоимость доставки в рублях либо `ValueError` |
| `apply_discount()` | Стоимость заказа после применения скидки либо `ValueError` |
| `calculate_final_cost()` | Итоговая стоимость заказа либо исключение из вызываемых функций |

### Классы эквивалентности

| Класс | Условие | Ожидаемый результат |
|---|---|---|
| 1 | `0 < distance_km <= 5` | Стоимость доставки 150 руб. |
| 2 | `5 < distance_km <= 20` | Стоимость доставки 250 руб. |
| 3 | `20 < distance_km <= 50` | Стоимость доставки 400 руб. |
| 4 | `distance_km <= 0` или `distance_km > 50` | `ValueError` |
| 5 | `0 < weight_kg <= 10` | Доплаты за вес нет |
| 6 | `weight_kg > 10` | Доплата 150 руб. |
| 7 | `weight_kg <= 0` | `ValueError` |
| 8 | `customer_type = regular`, сумма `< 5000` | Скидки нет |
| 9 | `customer_type = regular`, сумма `>= 5000` | Скидка 5% |
| 10 | `customer_type = premium` | Скидка 10% |
| 11 | Неизвестный тип клиента | `ValueError` |
| 12 | `order_amount <= 0` | `ValueError` |

### Граничные значения

| Проверяемое условие | Границы | Ожидаемый результат |
|---|---|---|
| Первая зона доставки | `5` / `5.1` км | 150 / 250 руб. |
| Вторая зона доставки | `20` / `20.1` км | 250 / 400 руб. |
| Максимальная дальность | `50` / `50.1` км | 400 руб. / `ValueError` |
| Доплата за вес | `10` / `10.1` кг | без доплаты / +150 руб. |
| Минимальное расстояние | `0` / отрицательное | `ValueError` |
| Минимальный вес | `0` / отрицательное | `ValueError` |
| Порог скидки обычного клиента | `4999` / `5000` руб. | без скидки / скидка 5% |
| Сумма заказа | `0` / отрицательное | `ValueError` |
